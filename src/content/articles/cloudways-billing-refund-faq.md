faqs:
  - question: Cloudways 支持退款吗？
    answer: Cloudways 没有标准的退款政策，但由于按小时计费，删除服务器后立即停止扣费。如果因平台故障造成损失，可以联系客服协商，官方通常会给账户余额补偿而非现金退款。
  - question: 服务器删除后数据还能恢复吗？
    answer: 不能。删除服务器会同时销毁其上的所有数据与备份。如果误删，只能依赖你在本地保留的备份文件。建议定期导出站点备份到本地或对象存储。
  - question: 可以降配吗？比如从 4GB 降到 2GB？
    answer: 内存与 CPU 可以降配，但已加购的存储扩容不可缩减。降配通常需要重建服务器并迁移数据，建议联系客服协助。
  - question: Cloudways 支持哪些应用类型？
    answer: 官方一键部署支持 WordPress、WooCommerce、Magento、Laravel、PHP 自定义应用等。不支持 Windows / .NET 环境，也不能直接一键部署 Node.js 或 Go 服务（可通过 SSH 自行安装）。
  - question: 一台服务器可以放几个网站？
    answer: 技术上可以放多个，但 Cloudways 的计费模型是「一台服务器一个应用」。要在同一服务器上跑多站点，需要使用 WordPress 多站点（Multisite）功能，或在面板里添加多个应用并共享服务器资源。
  - question: 忘记密码或账号被锁怎么办？
    answer: 通过登录页的「忘记密码」重置。如果账号因多次失败登录被锁，联系 24/7 在线客服人工解锁。
  - question: 支持自动备份吗？多久一次？
    answer: 支持。默认提供定期自动备份，可在面板中提升到每 1 小时一次（需额外付费）。所有备份支持一键回滚。
  - question: 可以只买服务器不买域名吗？
    answer: 可以。域名与服务器是独立的，你可以在任何注册商购买域名，然后把 DNS 指向 Cloudways 服务器的 IP 即可。

## 计费与账单

### Cloudways 怎么收费？

**按小时累计，月底结算**。控制台展示的是月费估算值，实际账单是每台服务器的
「使用小时数 × 小时单价」加上独立计费的附加项。

这意味着月中删除服务器只需支付已用小时数的费用。

### 有哪些项目是单独计费的？

| 项目 | 计费方式 |
| --- | --- |
| 主服务器 | 按小时（含在月费里） |
| 额外存储扩容 | 按月，**不可缩减** |
| Staging 环境 | 按月 |
| 高频备份（1 小时一次） | 按月 |
| 独立 IP | 按月 |
| 超流量（AWS / GCP 底层） | 按 GB |

> 最容易忽略的是**额外存储扩容**——它只能往上加，不能减回去，会一直计费。

### 删除服务器后还会扣费吗？

主服务器不会。但**附加项不会随主服务器自动删除**：
Staging 环境、存储扩容、独立 IP 都需要手动清理。

建议每月初检查一次账单明细。

## 退款与取消

### 有退款政策吗？

Cloudways 没有标准退款窗口（不像有些主机商提供 30 天无理由）。
但由于按小时计费，**你随时可以停掉消费**，这在实质上比退款政策更灵活。

如果因平台故障导致业务损失，可以联系客服协商补偿。官方通常提供**账户余额补偿**，
而非现金退款。

### 怎么彻底取消账号？

1. 删除所有服务器与附加服务
2. 在账户设置中提交账号关闭申请
3. 确认最终账单已结清

**删除服务器 = 数据永久销毁**。取消前务必导出备份。

## 配置与扩容

### 怎么升级配置？

在 Cloudways 面板 → Servers → 选中服务器 → Vertical Scaling，
选择目标档位即可。**不需要重装系统，站点数据保留**，通常几分钟内完成。

### 能降配吗？

CPU 与内存可以降，但通常需要**重建服务器并迁移数据**（因为底层 IaaS 不支持在线缩容）。
已加购的存储扩容**无法缩减**。建议联系客服协助处理。

### 能换底层云厂商吗？

不能一键切换。换厂商等于新建服务器再迁移数据。
好在 Cloudways 提供免费迁移服务，或者你可以用自带工具手动搬。

### 一台服务器能放几个站？

Cloudways 的模型是「**一台服务器对应一个应用**」。要跑多站点：

- 用 WordPress Multisite（多站点网络）功能
- 或在面板里为同一台服务器添加多个应用（共享 CPU / 内存资源）

多应用共享服务器时，任一站点流量暴涨都会影响其它站点，生产环境慎用。

## 支持的应用类型

**一键部署支持：**

- WordPress / WooCommerce
- Magento 2
- Laravel
- PHP 自定义应用
- PrestaShop、Joomla 等（部分需自定义）

**不支持：**

- Windows / .NET 环境
- Node.js / Python / Go 服务的一键部署（可通过 SSH 自行安装配置）
- 邮件服务器（Cloudways 不提供邮件托管）

## 客服与支持

### 怎么联系客服？

- **24/7 在线聊天**：面板右下角，首次响应通常 1–3 分钟
- **工单系统**：适合需要附日志的复杂问题
- **免费迁移**：通过面板的 Migration 入口提交

### 客服水平如何？

实测体验：**一线响应快，能解决常见问题**；涉及底层 IaaS 层面的复杂故障
（如机房网络异常）会转由工程师跟进，等待时间较长。

建议提问题时**附上具体错误信息、时间点和已尝试的步骤**，能显著缩短解决时间。

## 安全与备份

### 有自动备份吗？

有。默认提供定期备份，可在面板中提升频率（1–4 小时一次，需付费）。
所有备份支持一键回滚。

### 数据丢了能恢复吗？

如果服务器还在，可以用备份回滚。
**如果服务器已删除，数据无法恢复** —— 备份是随服务器一起销毁的。

**最佳实践**：定期把备份导出到本地或第三方对象存储（如 S3、Backblaze B2）。
不要把唯一的数据副本放在同一台服务器上。

### 有免费 SSL 吗？

有。Cloudways 自动签发并续期 Let's Encrypt 证书。
也支持上传自定义证书（如企业 EV 证书）。
